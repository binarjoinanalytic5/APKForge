# العمال والمحولات (Celery + Redis — ADR-002)

## المرحلة 1

- `base.py` واجهة المحول + السجل (يفشل مغلقًا عند نقص الإعلان).
- `manifest.py` تحميل `plugin.yaml` والتحقق منه (توأم بوابة العقود).
- `loader.py` اكتشاف `plugins/*/plugin.yaml` + `adapter.py` وربط الحدود
  من الإعلان (المجلدات `_`-بادئة مرجعية وتُتخطَّى).
- `runner.py` تنفيذ واحد بحدود مع تقرير صريح (لا تخمين أبدًا).
- `celery_app.py` ربط Celery للمرحلة 2 — يُستورَد بأمان بلا وسيط اليوم.

## القاعدة

النواة لا تستدعي أي أداة مباشرة — كل أداة خلف محول يعلن:
الاسم والإصدار، الأداة وإصدارها، مخططات الدخل/الخرج، والحدود.
التنفيذ الفعلي: عملية فرعية معزولة وفق `plugin.yaml` (JSON عبر
stdin/stdout، السجلات على stderr، خروج غير صفري = فشل صريح).

## إضافة جديدة

مجلد `plugins/<name>/` يحوي `plugin.yaml` (يطابق
`docs/plugin.schema.json`) و`adapter.py` (صنف `Adapter(ToolAdapter)`)
و`run.py` (متحدث البروتوكول) — تُكتشَف تلقائيًا عند الإقلاع.
