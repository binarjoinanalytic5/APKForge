# النواة (FastAPI نمطي)

المرحلة 0: هيكل + نبض + ثوابت العقود المجمدة. المسارات الكاملة (v1)
تُنفَّذ في المرحلة 1 وفق `docs/openapi.yaml` — العقد سابق للتنفيذ دائمًا.

## التشغيل المحلي (المرحلة 1+)

```sh
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

## ملاحظة التثبيت

`requirements.txt` حدود دنيا في المرحلة 0؛ ملفات القفل
(`pip-compile`) إلزامية قبل أي نشر إنتاجي (المنع 9).
