# قاعدة البيانات (DATABASE)

## المحرك

SQLite ملفي (`APKFORGE_DB`، افتراضيًا `data/apkforge.db`) — قرار ADR-004
(الخلفيات المحلية أولًا). PostgreSQL في المرحلة 2 خلف الواجهة نفسها.

## الترحيلات (`backend/migrations/` + `app/core/migrations.py`)

| الإصدار | المحتوى |
|---|---|
| `001_initial` | الجداول الخمسة الأساسية (مستعادة حرفيًا من مخطط المرحلة 1) |
| `002_system_config` | جدول الأعلام `system_config` (حالة التهيئة وملف المدير) |
| `003_job_indexes` | الفهارس الساخنة (مشاريع المهام والحالات والتدقيق) |

- السجل `schema_migrations(version, name, applied_at)` — كل ترحيل يُطبَّق
  مرة واحدة فقط داخل معاملة (فشل = rollback + سبب صريح).
- القواعد القديمة (جداول بلا سجل) تُعامَل كخط أساس: يُسجَّل 001 دون
  إعادة تنفيذ ثم تُطبَّق اللاحقة — **البيانات لا تُمسّ أبدًا**.
- `SqliteStore` يرحّل عند الإقلاع تلقائيًا؛ والمحرك يتحقق (`pending=[]`)
  ضمن فحوص الصحة.

## الجداول (مستعادة من الكود — RECOVERED)

`users` (المصادقة والأدوار) · `projects` · `jobs` (المهام وحالاتها)
· `artifacts` (الملفات المُعنوَنَة) · `audit` (سجل التدقيق الإلحاقي)
· `system_config` (الأعلام) · `schema_migrations` (السجل).

لا اشتراكات ولا مدفوعات ولا استحقاقات — المشروع لا يملك هذه الأنظمة،
فلا تُنشَأ جداول تخمينية. القيود: مفاتيح أساسية و`UNIQUE` ضمني
و`NOT NULL` من التعريفات، والفهارس في 003.

## البذور

لا صفوف بذور عمدًا: لا مدير افتراضي ولا أسرار ثابتة. أول مدير يُنشَأ
عبر `/setup/admin` (صفحة الإعداد الأولى) ثم يُغلَق المسار (403 دائمًا).
