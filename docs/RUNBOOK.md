# دليل التشغيل (RUNBOOK)

## الإقلاع اليومي

```sh
./apkforge            # يتحقق من كل شيء ويشغّل الناقص فقط
./apkforge --status   # الحالة والمنافذ والروابط
./apkforge --stop     # إيقاف الخدمات
```

## أين ماذا

| الشيء | المكان |
|---|---|
| الإعداد المحلي | `.env` (صلاحيات 600، لا يُودَع) |
| القاعدة والملفات | `data/` (قاعدة + blobs + work) |
| البيئة الافتراضية | `.venv/` |
| أدوات محلية | `.tools/` (node/apktool عند التوفير الذاتي) |
| السجلات | `logs/{bootstrap,server,database,migrations,health,errors}/` |
| الحالة والحوكمة | `.governance/` (حالة + pids + تقارير + تدقيق) |

## عمليات شائعة

- **تغيير المنافذ**: عدّل `.env` (`APKFORGE_PORT`/`APKFORGE_WEB_PORT`)
  ثم `./apkforge` — أو دعه يلتقط بديلًا حتميًا عند التعارض تلقائيًا.
- **إعادة البناء**: `./apkforge` يعيد بناء الواجهة عند تغير القفل فقط.
- **تدوير المفتاح**: بدّل `APKFORGE_KEY` في `.env` وأعد التشغيل (يُبطِل
  الرموز القديمة — نفّذها واعيًا).
- **إعادة التطوير**: `./apkforge --reset-dev --yes` (ينسخ `.env`
  احتياطيًا؛ يرفض العمل إطلاقًا إذا `APKFORGE_ENV=prod`).
- **النسخ الاحتياطي**: انسخ `data/` و`.env` — بهما تُستعاد الحالة كاملة.

## المراقبة

- نبض الخلفية: `GET /api/v1/health` · حالة التهيئة:
  `GET /api/v1/setup/status` · تقارير الصحة: `logs/health/*.json`.
- لا يُعتبَر أي `READY` حقيقيًا إلا بـ 11 فحصًا أخضر (عمليات + منافذ +
  HTTP + قاعدة + ترحيلات + مصادقة سالبة + صفحة).
