# ADR-003: تخزين الكائنات SeaweedFS عبر S3 API (مقبول)

التاريخ: 2026-10-08 · الحالة: **مقبول** · المرحلة: 0

## السياق

المنصة تخزن APKs ومخرجات (S3 API هو المعيار). المرشحان:
MinIO وSeaweedFS — كلاهما متوافق مع S3.

## القرار

**SeaweedFS** افتراضيًا، مع **تجريد S3** في الكود يسمح بالتبديل دون مساس.

## المبرر

- الرخصة: SeaweedFS برخصة **Apache-2.0** مقابل AGPL في MinIO —
  انسجامًا مع رخصة المنصة (Apache-2.0) وقاعدة الرخص النظيفة.
- الوظيفة: S3 API كافٍ لحاجتنا في الحالتين — لا ميزة تقنية حاسمة لـMinIO هنا.

## العواقب

- `infra/compose.yaml` يشغّل SeaweedFS (منفذ S3).
- طبقة التخزين في النواة تتحدث S3 حصرًا — أي بديل S3 يبقى ممكنًا.
