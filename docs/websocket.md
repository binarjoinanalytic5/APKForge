# بروتوكول WebSocket v1 (بث سجلات المهام)

النقطة: `WS /api/v1/ws/jobs/{job_id}` — المصادقة: `?token=<JWT>` عند الاتصال.

## إطارات الخادم → العميل (JSON سطرًا)

| النوع | الحقول | المعنى |
|---|---|---|
| `hello` | `job_id`, `status` | تأكيد الاشتراك + الحالة الراهنة |
| `log` | `seq`, `ts`, `stream` (`stdout`/`stderr`), `line` | سطر سجل متسلسل |
| `progress` | `seq`, `percent`, `stage` | تقدم (0–100) مع اسم المرحلة |
| `status` | `seq`, `status`, `reason?` | تغير حالة المهمة |
| `bye` | `status`, `summary?` | نهاية البث (نجاح/فشل/إلغاء) ثم إغلاق |

## القواعد

- `seq` متسلسل من 1 لكل اتصال — الفجوة تعني فقدًا ويُعاد الطلب عبر REST.
- نبضة `ping` كل 30 ثانية؛ غياب `pong` دقيقتين = إغلاق.
- إلغاء المهمة عبر REST فقط (`DELETE /jobs/{id}` في v1.1) — القناة للقراءة.
- حد 100 مشترك للمهمة؛ الزائد يُرفَض بـ `429 + retry_after`.
