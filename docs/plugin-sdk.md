# Plugin SDK v1 (عقد مجمد)

الإصدار: **1.0.0** — أي كسر يتطلب إصدارًا رئيسيًا ومسار هجرة.

## 1. المبدأ

كل أداة خارجية (Apktool، JADX، …) تُغلَّف كحزمة إضافة مستقلة:

```
Input (JSON عبر stdin) → Process (عملية فرعية معزولة) → Output (JSON عبر stdout)
```

لا ربط ثنائي بالنواة، ولا استيراد لمكتباتها — عزل كامل عبر العملية.

## 2. ملف الإعلان `plugin.yaml`

الحقول الإلزامية (المخطط الآلي: `plugin.schema.json`):

| الحقل | المعنى |
|---|---|
| `name` | اسم فريد (حروف صغيرة وشرطات) |
| `version` | إصدار دلالي للحزمة |
| `sdk_version` | `1.0.0` حصرًا |
| `tool.name` / `tool.version` | الأداة المغلفة وإصدارها المثبت |
| `runtime.command` | أمر التنفيذ (مصفوفة، بلا shell) |
| `runtime.timeout_s` | المهلة القصوى (1–3600) |
| `runtime.memory_mb` | حد الذاكرة (64–16384) |
| `runtime.cpu` | حد المعالج (0.1–8.0) |
| `runtime.network` | `none` افتراضيًا (الشبكة استثناء موثق) |
| `license` | رخصة الحزمة (SPDX) |

حقول اختيارية: `description`، `inputs`/`outputs` (مخططات JSON حرة)، `capabilities`.

## 3. بروتوكول التنفيذ

1. النواة تكتب مدخلات JSON على stdin وتغلقه.
2. العملية تكتب **كائن JSON واحدًا** على stdout، والسجلات على stderr.
3. رمز الخروج 0 = نجاح؛ غيره = فشل صريح (لا تخمين).
4. تجاوز المهلة أو الذاكرة = قتل + حالة `failed` بسبب مسجل.

## 4. الأثر الإلزامي

كل تنفيذ يسجل: اسم الحزمة وإصدارها، الأداة وإصدارها، بصمة المدخلات،
بصمة المخرجات، المدة، رمز الخروج. مخرج بلا أثر يُرفَض.

## 5. المثال المرجعي

`plugins/_example/plugin.yaml` — يُتحقَّق آليًا في CI ضد المخطط.
